# ETVP Si-Photon Core X (SPCX v1.0)
Полный цифровой макет фотонного чипа для экспериментальной проверки ETVP.

Содержит:
- **etvp_spcx_v1.gds** — GDSII-топология для MPW-заказа (TowerJazz, IMEC).
- **ETVP_12.5_SOLIDSTATE.py** — эмуляция чипа и протокол Prototype Zero.
- **chip_visualization.py** — 3D-визуализация архитектуры (matplotlib + plotly).

Статус: Готов к инженерной верификации и производству.
