# ETVP Si-Photon Core X (SPCX v1.0)

**Цифровой двойник фотонного чипа для экспериментальной проверки ETVP (Теории Единого Топологического Вакуумного Поля).**

Этот репозиторий содержит полный пакет для воспроизведения и верификации: от топологии до 3D-визуализации.

---

## 📁 Что внутри?

| Файл | Назначение |
|------|------------|
| `ETVP_SiPhoton_CoreX.gds` | **GDSII-макет** чипа для отправки на фабрики (MPW-заказы). Включает 256 колец, JPA, MEMS и спираль памяти. |
| `ETVP_SiPhoton_CoreX.gds.tech` | **Технологическая карта** — слои, материалы (Si₃N₄, поли-Si, Al) и правила проектирования (DRC). |
| `ETVP_chip_visualization.py` | **Python-скрипт** для 3D-визуализации чипа (статичной и интерактивной). |

---

## 🔬 Что это и зачем?

Это не просто набор файлов — это **инструмент для экспериментальной физики**:

- **Если вы инженер**: загрузите `.gds` в систему фаундри (TowerJazz, IMEC) и закажите чип.
- **Если вы физик**: используйте макет для проверки предсказаний ETVP (например, измерение `α⁻¹` и `G`).
- **Если вы программист**: запустите визуализацию, чтобы понять архитектуру «слоёв» (кольца, pn-переходы, JPA, MEMS).

---

## 🚀 Как начать?

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/sania-369/ETVP_AI.git
   cd ETVP_AI/XXX
   ```

2. **Запустите 3D-визуализацию:**
   ```bash
   pip install matplotlib plotly numpy
   python ETVP_chip_visualization.py
   ```

3. **Откройте `chip_3d_plotly.html` в браузере**, чтобы вращать и масштабировать модель чипа.

4. **(Опционально) Закажите чип:**  
   Отправьте `ETVP_SiPhoton_CoreX.gds` в MPW-программу (Multi-Project Wafer). Для этого вам понадобится доступ к фабрике или университетский контракт.
